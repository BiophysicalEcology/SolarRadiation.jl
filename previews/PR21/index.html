API Reference

☀️ Sun position

Solar declination, zenith and azimuth angles, day length and the sun distance factor for any latitude, day and time, including polar day and night.

🌈 Spectral irradiance

Direct and diffuse irradiance at 111 wavelengths from 290 to 4000 nm, after Rayleigh scattering, aerosols, ozone and water vapour, integrated to global irradiance.

🌤️ Diffuse models

Choose no scattering, the tabulated UV scattering of Dave and Furukawa or the full Chandrasekhar solution, by passing a type.

⛰️ Terrain

Elevation, pressure, albedo, slope, aspect and horizon angles are all part of the site description.

🌍 Poles to equator

Midnight sun, polar night, the equatorial double peak and the tropics, from the same functions.

🗺️ Maps

Aerosol profiles from the Global Aerosol Data Set and rasters from RasterDataSources.jl give global maps of clear-sky radiation.

📏 Units and speed

Every input and output uses Unitful.jl. Repeated calls reuse buffers and are type-stable and nearly non-allocating.

How to install SolarRadiation.jl? ​

SolarRadiation.jl can be installed from the Julia REPL:

julia
julia> using Pkg
julia> Pkg.add(url = "https://github.com/BiophysicalEcology/SolarRadiation.jl")

Model ​

The calculations follow McCullough and Porter (1971), as used in the microclimate model of NicheMapR. See the Introduction for the model and how the package is organised.
